# robosuite reward references

The v1.4.1 Lift design has reach plus discrete grasp shaping and binary lift success, without continuous intermediate lift progress. PickPlace uses a grasp-conditioned height-varying lift stage. TwoArmLift uses a height-proportional lifting reward. These are design references only; treatment does not copy either task reward.

Sources: https://github.com/ARISE-Initiative/robosuite/blob/v1.4.1/robosuite/environments/manipulation/lift.py ; https://github.com/ARISE-Initiative/robosuite/blob/v1.4.1/robosuite/environments/manipulation/pick_place.py ; https://github.com/ARISE-Initiative/robosuite/blob/v1.4.1/robosuite/environments/manipulation/two_arm_lift.py
